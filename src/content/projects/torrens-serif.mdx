## What it is

A soft serif display family. One variable font covers every weight from 100 to 900, upright and italic.

It is a modified [Fraunces](https://github.com/undercasetype/Fraunces) under a new name, not a typeface drawn from scratch. The letterform design is Phaedra Charles and Flavia Zimbardi's, of Undercase Type. What Torrens Serif adds is the recipe and the packaging.

## What I changed

- **Softness at the maximum**, so serifs and terminals are fully rounded.
- **The heading cut, fixed.** Fraunces changes shape with size; this keeps the cut meant for titles: sturdy strokes and tight spacing.
- **Weight kept as a live axis**, with the default moved from Black to Regular.
- **Upright `h m n s` and a plain `&` by default.** Fraunces' leaning "wonky" letters and its swash ampersand are still in the font, behind stylistic sets.
- **Straightened J, j and f.** Fraunces bends the stems of these three letters sideways just before the hook. Here the stems run straight, and the hooks are the original curves slid into place, so they match the other letters at every weight. The f is a little wider so its hook still clears tall neighbors.

## Using it

[Download Torrens Serif 1.0](https://github.com/bybrooklyn/torrens-serif/releases/download/v1.0/Torrens-Serif-1.0.zip), or see the [repository](https://github.com/bybrooklyn/torrens-serif) for the fonts, the build script and the Fraunces files it builds from.

On a website, copy the two variable `.woff2` files and `fonts.css` into the same folder:

```css
h1,
h2 {
    font-family: "Torrens Serif", Georgia, serif;
    font-weight: 400;
    line-height: 1.12;
}

/* wonky letters and the swash ampersand */
.fancy {
    font-feature-settings: "ss01", "ss02";
}
```

On a computer, install either the two variable files or the static ones, not both. They share a family name and will collide.

It is cut for headings. At small sizes it sets tight, which is why the paragraphs on this site are in Fraunces itself.
