mdQuire writes Markdown the way a word processor writes a page: bold, lists, tables, pictures, headings. The file underneath stays plain Markdown, and what was not changed keeps every byte it had.

Documents can live in the browser, in files and folders on the computer, or in a GitHub repository. A GitHub token is kept only in the browser and sent only to GitHub.
