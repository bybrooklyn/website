This site is built with [Astro](https://astro.build) and Bun and served from Cloudflare Pages. Posts are MDX files. There is no analytics and no tracking.

## Color

The site is dark, on a near-black purple. A post can change the accent color in its frontmatter:

```yaml
accent: pink
```

## Scripts

There is very little JavaScript: a few lines that tell the page transition which way to slide, a few that mark your place in a page's contents, and a few that open out the email link in the footer.
